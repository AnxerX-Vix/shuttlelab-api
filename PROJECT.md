## 1. Arsitektur Sistem

Aplikasi ShuttleLab dibangun menggunakan arsitektur modular monorepo terpisah:
- **`shuttlelab-api`**: Backend REST API berbasis Node.js & Express.js yang terhubung langsung ke Supabase PostgreSQL, dilengkapi CORS, dan siap di-deploy ke Vercel Serverless Functions.
- **`shuttlelab-pwa`**: Frontend Progressive Web App (PWA) berbasis React (Vite) dan Tailwind CSS, menggunakan Axios untuk konsumsi data API serta `localStorage` untuk fitur offline wishlist.

## 2. Skema Database Supabase (PostgreSQL)

Menggunakan 3 tabel relasional di Supabase: `categories`, `gears`, dan `techniques`.

```sql
-- 1. Tabel Categories
CREATE TABLE categories (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name VARCHAR(50) NOT NULL UNIQUE,
  slug VARCHAR(50) NOT NULL UNIQUE,
  icon VARCHAR(50),
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Tabel Gears (Katalog Perlengkapan)
CREATE TABLE gears (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  category_id BIGINT REFERENCES categories(id) ON DELETE SET NULL,
  name VARCHAR(120) NOT NULL,
  brand VARCHAR(60) NOT NULL,
  model VARCHAR(80),
  price_range VARCHAR(50),
  weight_grip VARCHAR(20),       -- Contoh: '3U/G5', '4U/G6'
  balance_point VARCHAR(30),     -- Contoh: 'Head-Heavy (305mm)'
  shaft_flexibility VARCHAR(30), -- Contoh: 'Stiff', 'Medium', 'Flexible'
  description TEXT,
  image_url TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. Tabel Techniques (Panduan Teknik & Footwork)
CREATE TABLE techniques (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  category VARCHAR(50) NOT NULL,    -- 'Footwork', 'Stroke', 'Service', 'Defense'
  difficulty VARCHAR(20) NOT NULL,  -- 'Beginner', 'Intermediate', 'Advanced'
  description TEXT NOT NULL,
  steps JSONB NOT NULL DEFAULT '[]'::jsonb, -- Array langkah: ["Langkah 1", "Langkah 2"]
  key_tips TEXT,
  image_url TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Index performa query
CREATE INDEX idx_gears_category ON gears(category_id);
CREATE INDEX idx_gears_brand ON gears(brand);
CREATE INDEX idx_techniques_difficulty ON techniques(difficulty);
CREATE INDEX idx_techniques_category ON techniques(category);
```

### Data Awal (Seed Data Ringkasan)
- **Categories**: Racket (`racket`), Shoes (`shoes`), Shuttlecock (`shuttlecock`), String & Grip (`string-grip`).
- **Gears**: Yonex Astrox 88D Pro, Victor Thruster Ryuga II, Li-Ning Aeronaut 9000, Yonex Power Cushion 65 Z3, Victor P9200III.
- **Techniques**: Basic Split Step Footwork, Forehand Overhead Clear, Backhand Defense Drive, Forehand Low Service, Net Drop Shot.

## 3. Spesifikasi REST API Backend (`shuttlelab-api`)

Arsitektur folder mengacu pada standar Modul 1 Praktikum PPB:

### Struktur Folder
- `config/supabase.js`: Inisialisasi `@supabase/supabase-js` menggunakan `SUPABASE_URL` dan `SUPABASE_ANON_KEY`.
- `models/categoryModel.js`: Query tabel `categories`.
- `models/gearModel.js`: Query tabel `gears` (termasuk join dengan `categories`).
- `models/techniqueModel.js`: Query tabel `techniques`.
- `controllers/gearController.js`: Logika validasi dan response JSON untuk gear.
- `controllers/techniqueController.js`: Logika validasi dan response JSON untuk teknik.
- `controllers/categoryController.js`: Logika response JSON kategori gear.
- `routes/gearRoutes.js`: Router endpoint `/api/gears`.
- `routes/techniqueRoutes.js`: Router endpoint `/api/techniques`.
- `routes/categoryRoutes.js`: Router endpoint `/api/categories`.
- `index.js`: Instansiasi Express, `app.use(cors())`, `app.use(express.json())`, mounting router, dan export handler untuk Vercel.

### Daftar Endpoint REST API Lengkap

| Method | Endpoint | Deskripsi | Query / Body Param | Respon Sukses |
|---|---|---|---|---|
| `GET` | `/api/health` | Status server backend | - | `200 { status: 'ok', time: '...' }` |
| `GET` | `/api/categories` | Ambil semua kategori gear | - | `200 [ { id, name, slug, icon } ]` |
| `GET` | `/api/gears` | Ambil daftar katalog gear | `?category=...&search=...` | `200 [ { id, name, brand, ... } ]` |
| `GET` | `/api/gears/:id` | Ambil detail gear berdasarkan ID | Params: `id` | `200 { id, name, brand, ... }` |
| `POST` | `/api/gears` | Tambah gear baru | Body JSON: `name`, `brand`, `category_id`, dll. | `201 { message, data }` |
| `PUT` | `/api/gears/:id` | Perbarui data gear | Params: `id`, Body JSON | `200 { message, data }` |
| `DELETE` | `/api/gears/:id` | Hapus gear | Params: `id` | `200 { message: 'Gear deleted' }` |
| `GET` | `/api/techniques` | Ambil daftar panduan teknik | `?difficulty=...&category=...` | `200 [ { id, name, difficulty, ... } ]` |
| `GET` | `/api/techniques/:id` | Ambil detail langkah teknik | Params: `id` | `200 { id, name, steps, ... }` |
| `POST` | `/api/techniques` | Tambah panduan teknik baru | Body JSON: `name`, `category`, `steps`, dll. | `201 { message, data }` |
| `PUT` | `/api/techniques/:id` | Perbarui data panduan teknik | Params: `id`, Body JSON | `200 { message, data }` |
| `DELETE` | `/api/techniques/:id` | Hapus panduan teknik | Params: `id` | `200 { message: 'Technique deleted' }` |

## 4. Pemetaan 5 Halaman Frontend PWA (`shuttlelab-pwa`)

Seluruh halaman didesain mobile-first dengan kontainer maksimal selebar mobile/tablet ringkas (`max-w-md mx-auto min-h-screen bg-slate-50`).

### 1. Halaman List 1: Katalog Gear Badminton (`/` atau `/gears`)
- **Tujuan**: Menampilkan katalog raket, sepatu, dan shuttlecock.
- **Sumber Data**: `GET /api/gears` (dan `GET /api/categories` untuk filter chips).
- **Fitur UI**:
  - Top Bar: Logo ShuttleLab & input search gear.
  - Horizontal Scroll Category Chips (All, Racket, Shoes, Shuttlecock).
  - Grid Card Gear (foto produk, badge kategori, nama produk, brand, kisaran harga, tombol pintas bookmark/wishlist).
  - Pull-to-refresh & skeleton loader saat fetch data.

### 2. Halaman Detail 1: Detail Spesifikasi Gear (`/gears/:id`)
- **Tujuan**: Membedah spesifikasi teknis raket/sepatu pilihan pemain.
- **Sumber Data**: `GET /api/gears/:id`.
- **Fitur UI**:
  - Tombol Back navigasi di pojok kiri atas.
  - Gambar produk resolusi tajam dengan background kontras.
  - Spesifikasi Grid Card: Weight/Grip, Balance Point, Shaft Flexibility, Price Range.
  - Deskripsi karakteristik bermain (Head-heavy untuk smash bertenaga, etc.).
  - Tombol Aksi Bawah: "Simpan ke Wishlist" (toggle simpan/hapus dari `localStorage`).

### 3. Halaman List 2: Panduan Teknik & Footwork (`/techniques`)
- **Tujuan**: Daftar teknik badminton dari footwork hingga pukulan smash/drop.
- **Sumber Data**: `GET /api/techniques`.
- **Fitur UI**:
  - Filter Tabs Difficulty: All, Beginner, Intermediate, Advanced.
  - List Card Teknik: Ikon kategori pukulan/footwork, nama teknik, badge tingkat kesulitan dengan warna semantik (Hijau: Beginner, Kuning: Intermediate, Merah: Advanced).
  - Cuplikan deskripsi ringkas dan indikator jumlah langkah.

### 4. Halaman Detail 2: Detail Langkah Teknik (`/techniques/:id`)
- **Tujuan**: Memberikan instruksi step-by-step pelaksanaan teknik yang aman dan benar.
- **Sumber Data**: `GET /api/techniques/:id`.
- **Fitur UI**:
  - Header detail teknik dengan badge kategori dan kesulitan.
  - Visual diagram/ilustrasi posisi lapangan.
  - Ordered Step-by-Step Card (nomor langkah 1, 2, 3 berurutan vertikal dengan konektor garis).
  - Box Callout "Pro Tips / Kunci Sukses" beraksen hijau lapangan.

### 5. Halaman Profile / About + Wishlist Lokal (`/profile`)
- **Tujuan**: Memenuhi syarat halaman profile praktikan sekaligus mengelola wishlist offline.
- **Sumber Data**: Biodata statis praktikan + `localStorage.getItem('shuttlelab_wishlist')`.
- **Fitur UI**:
  - Profile Card: Foto praktikan, Nama Lengkap, NIM, Program Studi, Kelas Praktikum PPB 2026.
  - About Card: Penjelasan aplikasi ShuttleLab, versi PWA, dan status koneksi API.
  - Tab / Section Wishlist Tersimpan: Daftar gear yang telah dibookmark oleh user di browser, bisa diklik untuk menuju detail gear atau dihapus langsung dari wishlist.
  - Tombol "Hapus Semua Wishlist".

### Navigasi Bottom Navigation Bar
Menetap di bagian bawah layar viewport mobile:
1. Tab 1: **Gear** (`/gears`) — Ikon Raket / Shopping Bag
2. Tab 2: **Teknik** (`/techniques`) — Ikon Shuttlecock / Activity Book
3. Tab 3: **Profile** (`/profile`) — Ikon User / Profile Badge

## 5. Fitur Progressive Web App (PWA)
- Didukung oleh `vite-plugin-pwa` dengan `registerType: 'autoUpdate'`.
- Manifest PWA: Nama "ShuttleLab", icons maskable 192x192 & 512x512, background `#0F172A`, theme color `#059669`.
- Service Worker caching untuk asset statis dan fallback offline.
