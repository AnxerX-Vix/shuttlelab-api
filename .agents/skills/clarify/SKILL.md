# Clarify (Impeccable Design Suite)

Rewrite unclear interface text so users understand what happened, what matters, and what to do next.

## Core Rules

1. **Eliminate AI Clichés**:
   - Ban generic AI adjectives: "komprehensif", "eksplosif", "mengoptimalkan", "terdepan", "revolusioner".
   - Ban robotic passive actions: "pelajari lebih lanjut", "klik di sini untuk melihat".
   - Use direct, active, punchy verbs: "Lihat spek", "Buka panduan", "Simpan", "Hapus".

2. **Speak Authentic Domain Language**:
   - Use real badminton terminology used by players and stringers:
     - "Tarik senar", "Tension", "Grip", "Head-heavy", "Even-balance", "Smash tajam", "Lob serang", "Netting tipis", "Footwork lincah", "Raket cadangan".
   - Avoid sterile dictionary translations that no player actually uses.

3. **Short & Decisive**:
   - Empty states must be direct: "Belum ada raket yang kamu simpan" instead of "Wah, sepertinya Anda belum memiliki item dalam daftar keinginan Anda!".
   - Headings must name the content directly: "Katalog Gear" instead of "Jelajahi Koleksi Perlengkapan Badminton Terbaik Kami".
